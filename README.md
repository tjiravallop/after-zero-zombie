# AFTER ZERO — ตื่นหลังความตาย

Prototype 0.2 ของเกมซอมบี้มีสติ เล่นบนเบราว์เซอร์แบบเลือกการกระทำวันต่อวัน โปรเจกต์นี้อยู่แยกจาก One Life in Sect และไม่ต้องโหลดไฟล์จากเกมเดิม

## เปิดเล่น

ดับเบิลคลิก `play.cmd` หรือเปิด `index.html` ด้วย Edge / Chrome ได้เลย ไม่ต้องติดตั้งแพ็กเกจหรือเปิดเซิร์ฟเวอร์ ใช้ได้ออฟไลน์

เลือกคำตอบตอนตื่น จากนั้นเลือกกิจกรรมหรือเดินทาง **1 ครั้ง = 1 วัน** เหตุการณ์ต่อจากกิจกรรมไม่เสียวันซ้ำ ส่วนบทสนทนาตอนเช้าไม่ใช้วัน เวลาจะเดินเมื่อกดเล่นเท่านั้น

- สุขภาพหมด: ร่างกายตาย พักที่บ้านหรือใช้ชุดเย็บแผลเพื่อฟื้น
- ความหิว: 0 คืออิ่ม ตั้งแต่ 85 เสียสุขภาพทุกวัน เลือกหาเนื้อมนุษย์จากศพ ล่าคนเป็น หรือดื่มเลือดที่โรงพยาบาล เลือกทนหิวได้ทุกสถานที่ และทำกิจกรรมอื่นต่อได้โดยไม่ต้องกินก่อน
- การออกหาเหยื่อยังไม่ทำให้กิน ต้องเลือกเองในเหตุการณ์ว่าจะกิน ช่วย หรือถอย แต่ละการตัดสินใจมีผลตามหลัง เลือดในตู้แช่มี 8 ถุงและใช้แล้วหมดไป อาหารกระป๋องเอาไว้ให้มนุษย์ กินแล้วไม่อิ่มสำหรับซอมบี้
- การฆ่าแล้วกินคนไม่ลดสติโดยตรง แต่กระทบความไว้ใจและความเห็นใจ การฝืนช่วยมนุษย์เมื่อหิวตั้งแต่ 75 เสียสติเพิ่ม 6 และสุขภาพ 3 โดยมีคำเตือนก่อนเลือก
- สติ: ส่งผลต่อตัวเลือก หากเป็น 0 ติดต่อกัน 3 วันจะเสียตัวตน ใช้รูปถ่ายฟื้นสติได้
- หน้าหลักแสดงสุขภาพ ความหิว สติ และอาการปัจจุบัน กิจกรรมอื่นกับตัวเลขรองกดขยายดูได้ แผงเส้นทางบอกความพร้อมโดยไม่ต้องไล่คำนวณทุกค่า เปลี่ยนเป้าหมายที่ติดตามได้โดยไม่ล็อกเส้นทาง
- แผนที่มี 5 สถานที่ ต้องเดินทางตามทางเชื่อมและเสียวันในการเดินทาง

มี 7 บทจบ: ตาย เสียสติ ราชาซอมบี้ วิวัฒนาการเป็นสายพันธุ์ใหม่ กลับเป็นมนุษย์ มนุษยชาติสูญพันธุ์ และอยู่รอดครบ 60 วัน พร้อมเหตุการณ์เขียนไว้ 19 เหตุการณ์

## เซฟ

บันทึกอัตโนมัติในเบราว์เซอร์เดิม เปิดเมนูมุมขวาบนเพื่อส่งออก/นำเข้า JSON หรือเริ่มชีวิตใหม่ บทจบที่สะสมไว้ยังอยู่เมื่อเริ่มใหม่ ใช้คีย์ `awake-zombie-prototype-save-v1` และ `awake-zombie-prototype-meta-v1` แยกจากเกมเดิม

เซฟเวอร์ชัน 1 จะถูกแปลงเป็นเวอร์ชัน 2 อัตโนมัติ โดยของกินเดิมกลายเป็นอาหารกระป๋องสำหรับมนุษย์ เก็บวัน สถานะ บทจบ และเหตุการณ์ที่กำลังเลือกไว้ ประวัติการฆ่า/ช่วยเริ่มนับจากกติกาใหม่

เบราว์เซอร์บางตัวจัดเก็บเซฟของไฟล์ที่เปิดตรงต่างกัน หากย้ายโฟลเดอร์หรือเปลี่ยนเบราว์เซอร์ ให้ส่งออกเซฟก่อน หากบันทึกไม่ได้ หน้าจอจะแจ้งให้ส่งออกแทน

## โครงสร้างและส่วนที่นำกลับมาใช้

- `engine.js`: ยก `clamp` และ `readStatePath` มาจาก `app.js` ของ One Life in Sect ปรับแนวทางผลลัพธ์แบบ stat effect เงื่อนไขกิจกรรม และบันทึกย้อนหลังมาใช้กับเกมนี้
- `data/catalog.js`: สถานที่ กิจกรรม เหตุการณ์ ตัวเลือก และบทจบของเกมซอมบี้
- `app.js`: UI เซฟ และฉากพิกเซล Canvas ที่เขียนใหม่สำหรับเกมนี้
- `index.html` / `styles.css`: หน้าเว็บ responsive และหน้าต่างเหตุการณ์

ส่วนการเล่นรายวัน สมดุลทรัพยากร เส้นทางบทจบ และภาพเป็นงานใหม่ โปรเจกต์ไม่มี dependency ต่อ runtime ของเกมเซียน ไม่มี build step ไม่มีบริการภายนอก

## ตรวจสอบ

ใช้ Node.js รัน `node tests/engine.cjs` สำหรับกติกาเกม และ `node tests/browser.cjs` สำหรับเบราว์เซอร์ ตัวทดสอบเบราว์เซอร์ต้องมี Playwright และ Edge (กำหนด executablePath ในไฟล์ทดสอบตามเครื่องได้)

ผลรอบนี้: engine 20/20 และ browser 13/13 ผ่าน ตรวจเส้นทางจากชีวิตใหม่ถึงบทจบหลักทั้ง 4 แบบโดยไม่เติมค่าสถานะ ตรวจการเลือกกิน/ไม่กิน เลือดที่มีจำกัด ผลจากการช่วยคน การย้ายเซฟเดิม รีโหลดกลางเหตุการณ์ นำเข้าเซฟ และเปิดผ่าน file URL รวมถึงภาพที่ความกว้าง 320, 390 และ 1280px ผลกับภาพอยู่ใน `outputs/`

ขอบเขตตอนนี้เป็นต้นแบบทดสอบวงจรการเล่นและทิศทางงานภาพ ยังต้องเพลย์เทสกับผู้เล่นจริงเพื่อปรับความยาก ความหลากหลายของเหตุการณ์ และจังหวะเล่าเรื่อง
